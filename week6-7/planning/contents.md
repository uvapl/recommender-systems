# Project details

## Output

The project is treated as group work, and all group members receive the same grade.

The output for this assignment therefore consists of three parts, all due: **March 20th at 11:00h**:

1. A short presentation/pitch delivered during the final tutorial meeting (5 to 7 minutes max)
2. A written report that elaborates on and substantiates the key findings highlighted in the presentation (2000 - 3000 words max)
3. Code base and data, preferably in the form of a github repository. All code should be well documented, straightforward to run by the staff, and produce the results as described in the report.  

## Timeline

### Week 6 - Monday

Goal: Approve the plan or find concrete alternative
Discuss and refine:

* What RS domain are you focusing on?
* What is your focus/research question?
* What technical work will you do? (algorithm, data analysis, metric, comparison, simulation, …)
* Which course concepts (Dina) are central, and why?
* What data or resources will you rely on?
* How are tasks divided in the group?
* Check feasibility (given 40 hours of work per person)

### Week 6 - between Monday and Thursday

* work out the theoretical framework
* drafting how these concepts translate into design/evaluation choices
* experimenting with/investigating data
* setting up code
* specifying/implementing metrics or algorithms

### Week 6 - Thursday

Goal: check progress and individual contributions, get help with issues
Discuss:

* what has been done technically (e.g. code stubs, first runs, metric definitions)
* what has been done conceptually (e.g. literature overview, defined concepts, draft argument)
* each student can give a clear account of their activities so far
* each student can explain how their work contributes to the central idea
With our support:
* resolve issues
* adjust scope (if it is too ambitious, too small, or not well aligned)

### Week 7 - Monday

Goal: (mostly technical) show that the core of your project works end to end
Prepare to demonstrate a working MVP, for example:

* a basic recommender algorithm running on a small dataset
* an evaluation metric implemented and tested
* a preliminary data analysis with first results/visualizations
Discuss:
* how this MVP connects to your theoretical framework (Dina’s concepts)
* what still needs to be done before the final presentation (e.g. polishing analyses, deepening reflection, improving visuals)

### Week 7 - between Monday and Friday
* run final experiments
* draw conclusions
* analyse impact of results
* documenting and finalizing code
* running final tests/simulations/analyses
* create figures
* write final report

### Week 7 - Friday

Deadline final report (due before start of presentations)!

Goal: present your final integrated project

* 10 minute pitch per group, followed by brief questions.
* Present:
* the problem and RS domain
* your focus / research question
* your technical approach and main results
* theoretical justification


## Grading

| Component                                    | Weight |
|----------------------------------------------|--------|
| Technical effort	                           | 30%    |
| Theoretical justification & understanding	   | 30%    |
| Integration of technical & societal aspects  | 20%    |
| Presentation (pitch)	                       | 20%    |

You can use one of the projects proposed by us, but if you do so, your final project **grade is capped at 8.0** (no point deductions; only the maximum is limited).
