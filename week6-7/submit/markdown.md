# Submit

* Zorg ervoor dat het voorstel een duidelijk herkenbare naam heeft (bijvoorbeeld `report.md` of `report.pdf`).
* Check nog een allerlaatste keer dat je code goed werkt, voor je het inlevert.
* Submit de link naar de GitHub-**commit**.
  * Ga naar de pagina van de GitHub-repository en klik op de commit die je wilt inleveren (meestal de laatste commit).
  * Kopieer en plak de link in het formulier op de website.
  * Klik op verzenden.
  * Als je repositry private is, stuur ons dan een invite. GitHub-handel: simonpauw
